# MTE Systems — منصة إدارة ذكية للكافيهات والمطاعم والترفيه

منصة متكاملة لإدارة الكافيهات والمطاعم وصالات الألعاب (بلايستيشن + كمبيوتر) بواجهة عربية كاملة، تشمل الفوترة، المخزون، التقارير، الرواتب والحضور، العملاء والدليفري، ونظام طباعة احترافي بمصمم أوراق مرئي — مع تطبيق سطح مكتب (Electron) يعمل على كل جهاز باسم طابعة واحد.

> تصميم وتطوير: **م. مصطفى طلعت للحلول البرمجية**

---

## ✨ المميزات الرئيسية

### 🖨️ نظام الطباعة الاحترافي
- **مصمم أوراق مرئي**: ثلاث أوراق مستقلة (فاتورة / تحضير / استهلاك) — لكل ورقة خطها وتذييلها وإعداداتها، مع معاينة حية.
- **تحكم دقيق**: إظهار/إخفاء وحجم خط كل عنصر (الشعار، الأرقام، التاريخ/الوقت، الكاشير، العميل، الهاتف، العنوان، الجدول، الإجماليات، الملاحظات) + فصل العنوان عن البيان.
- **ورقة التحضير**: رقم الطلب + رقم الفاتورة المرتبطة، بانر "طلب مُحدّث" (قابل للإخفاء)، و**جدول إجماليات زخرفي** (إجمالي القسم + إجمالي الفاتورة) بحجم خط مستقل لكل صف.
- **الطابعات**: طباعة USB بالاسم عبر وكيل محلي، توجيه كل قسم لمطبخه، **نسخ مستقلة لكل قسم**، طابعة افتراضية، وإعدادات "طابعتي" الخاصة بكل مستخدم.
- **نفس اسم الطابعة على كل الأجهزة**: بدون تغيير إعدادات عند التنقل — والطباعة من الهاتف تتم عبر الجهاز الرئيسي.
- **رمز QR قابل للمسح دائمًا**: حد أدنى 80px، منطقة أمان بيضاء، حدة بكسلات، مع تحكم في موضع الوصف (بجانب/أسفل) واتجاهه (أفقي/رأسي بالطول) وحجم خطه.
- **تفاصيل مطبخية**: دعم كامل للعربية، فتح درج الكاشير، قطع الورق، أرقام تسلسلية يومية، ومسار RAW احتياطي.

### 💰 الفوترة والدفع
- **ذاكرة دفع لكل فاتورة**: طريقة الدفع والدرج محفوظان لكل فاتورة — تغيير واحدة لا يمس الباقي.
- **طرق دفع وأدراج**: كاش/كارد/تحويل/محفظة + أدراج (صالة/تيك أوي/دليفري/كاشير/خزينة) بافتراضي ذكي حسب نوع الطلب.
- **دفع جزئي ومختلط**، خصم يدوي/نسبة بصلاحية مستقلة، نقل الفواتير بين الطاولات بصلاحيات منفصلة.
- **رمز QR لكل فاتورة**، وتتبع الحالة (مسودة/جزئي/مدفوع/ملغي).

### 🎮 إدارة صالات الألعاب
- جلسات بلايستيشن وكمبيوتر، تغيير عدد الدراعات أثناء الجلسة، أسعار مرنة، وتكلفة تفصيلية لكل فترة.

### ☕ الكافيه والمطعم
- طلبات الطاولات والتيك أوي والدليفري، شاشة مطبخ فورية، تتبع وقت التحضير، وإدارة القوائم (أصناف/فئات/أقسام/صور).

### 👥 العملاء والدليفري
- دليل عملاء بملخص مطابق للصفوف، رسوم توصيل تُجمع تلقائيًا في إجمالي الفاتورة المطبوعة.

### 👤 المستخدمون والصلاحيات
- صلاحيات دقيقة (خصم يدوي، نقل، مراجعة طلبات العملاء، خصم مرتبات...) وأدوار: مدير/موظف/كاشير/مطبخ/مالك.

### ⏱️ الورديات والحضور والرواتب
- **وردية لكل مستخدم** بملخص مدفوعات (حسب الطريقة والدرج)، تسجيل حضور وانصراف مع نافذة أيام وتعديل، رواتب وخصومات ومكافآت وسلف.

### 📦 المخزون والتكاليف
- مخزون نشط ومستودع، مواد خام مرتبطة بالأصناف، حركات مسجلة، ومصروفات بفئات وتقارير.

### 📊 التقارير
- مبيعات (يومي/أسبوعي/شهري/مخصص)، أصناف مباعة بفلترة زمنية، استهلاك، مالي، جلسات، ذروة، أداء موظفين — مع تصدير Excel وPDF.

### 🌐 لغات وإشعارات ومزامنة
- **عربي/إنجليزي/فرنسي** مع دعم RTL، إشعارات فورية (Socket.IO)، ومزامنة مزدوجة (MongoDB محلي + Atlas) مع مزامنة شبكة محلية.

## 🔧 التثبيت والتشغيل

```bash
# 1. استنساخ المشروع
git clone <repository-url>
cd project

# 2. تثبيت المكتبات
npm install
cd server && npm install && cd ..

# 3. إعداد متغيرات البيئة (server/.env)
# MONGO_URI=mongodb://localhost:27017/mte?replicaSet=rs0
# MONGODB_ATLAS_URI=mongodb+srv://... (اختياري)
# JWT_SECRET / EMAIL_USER / EMAIL_HOST ...

# 4. التشغيل اليومي (سيرفر + واجهة + سطح مكتب)
npm run desktop:dev:all
# ثم Ctrl+R داخل التطبيق بعد أي تعديل على الكود
```

### ⚠️ ملاحظات مهمة
- **البريد (Gmail)**: يُستخدم App Password (16 حرفًا بدون مسافات) وليس كلمة الدخول، مع دعم التشفير عبر `EMAIL_PASS_ENC` (`server/scripts/set-email-pass-enc.mjs`).
- **إعادة التشغيل**: أي تعديل على المصدر لا يظهر إلا بعد `npm run desktop:dev:all` ثم `Ctrl+R` — ملفات التثبيت الجاهزة لا تتحدث تلقائيًا.
- **الفحص**: `npm run typecheck` يجب أن يكون نظيفًا قبل التسليم.

## 🔐 الصلاحيات
